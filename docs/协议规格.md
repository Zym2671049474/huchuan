# 互传协议规格（逆向自 CatShare + 互传联盟）

> **这是本项目的核心资产。** 任何 agent 接手前必须先读本文。

## 1. 分层

```
┌─ 发现层：BLE GATT ──────────────────────────┐
│  接收方起 GATT Server 广播；发送方扫描并连接  │
│  交换：SSID / PSK / port / (mac 死字段)      │
└──────────────────────────────────────────────┘
              ↓ 拿到 SSID+PSK
┌─ 链路层：WiFi Direct (P2P) ─────────────────┐
│  WifiP2pConfig.setNetworkName(ssid)          │
│              .setPassphrase(psk)             │
└──────────────────────────────────────────────┘
              ↓ 拿到 groupOwnerAddress
┌─ 传输层：WebSocket ─────────────────────────┐
│  ws://<groupOwner>:<port>                    │
│  自定义文本协议（见 §4）                      │
└──────────────────────────────────────────────┘
```

## 2. BLE UUID（必须完全一致才能互通）

| 用途 | UUID |
|---|---|
| 广播 Service | `00003331-0000-1000-8000-008123456789` |
| GATT Service | `00009955-0000-1000-8000-00805f9b34fb` |
| Char **状态** (DeviceInfo) | `00009954-0000-1000-8000-00805f9b34fb` |
| Char **P2P 信息** (P2pInfo) | `00009953-0000-1000-8000-00805f9b34fb` |

## 3. 数据模型

```json
// DeviceInfo —— 接收方通过 CHAR_STATUS 暴露
{"state":0,"key":"<Base64 X.509 EC公钥>","mac":"02:00:00:00:00:00","catShare":7}

// P2pInfo —— 发送方通过 CHAR_P2P 写入
{"id":"a1b2","ssid":"...","psk":"...","mac":"...","port":12345,"key":"<Base64>","catShare":7}
```

> ⚠️ **`mac` 是死字段**：接收端解密后 `p2pInfo.mac` **从未被读取**。
> 连接只用 ssid/psk。全代码库对该字段的读取仅 1 处（解密赋值本身）。
> → **不需要 root，不需要 Shizuku。**

## 4. WebSocket 文本协议

格式：`type:id:name?payload`

```
正则：^(\w+):(\d+):(\w+)(\?(.*))?$
```

| 段 | 含义 |
|---|---|
| type | `action` / `req` / `resp` |
| id | 数字消息 ID |
| name | 动作名 |
| payload | 可选 JSON |

### status 消息
```json
action:<id>:status?{"taskId":"...","type":1,"reason":"ok","id":"..."}
```
`type`: `1`=成功 `3`=用户拒绝 `99`=特殊任务 ID

## 5. 加密（ECDH + AES-CTR）

```
1. 双方各生成 EC P-256 密钥对
2. 交换 Base64(X.509 encoded public key)
3. ECDH → generateSecret("TlsPremasterSecret")
4. AES/CTR/NoPadding，IV 固定 "0102030405060708"
5. 载荷 Base64 编码
```
**注意**：IV 是硬编码常量（协议要求，勿改）。
