# 操作规范

## 构建规范

- **只用 `./build.sh`**，不要手敲命令（避免踩 P003/P004）
- 每次改动后必须构建通过才算完成
- 构建产物在 `build/`，**不提交到 git**（见 `.gitignore`）

## 代码规范

- **纯 Java**，源码在 `app/src/`
- 目标 API：`minSdk 29` / `targetSdk 35`（与 CatShare 一致，保证协议兼容）
- **禁止**引入任何第三方库 —— 本机无法解析依赖
- 包结构：
  ```
  com.huchuan
    ├── MainActivity.java      入口 / UI
    ├── core/                  协议核心（BLE、P2P、加密）
    ├── net/                   WebSocket、传输
    └── ui/                    UI 辅助
  ```
- 命名：类 `PascalCase`，方法/变量 `camelCase`，常量 `UPPER_SNAKE`
- 所有日志用 `android.util.Log`，TAG = 类名

## 提交规范

```
<type>: <简述>

<可选正文：为什么这么改>
```

| type | 用途 |
|---|---|
| feat | 新功能 |
| fix | 修 bug |
| docs | 只改文档 |
| build | 构建脚本 |
| refactor | 重构（不改行为）|
| test | 测试相关 |
| chore | 杂项 |

**铁律：每次提交都要更新 `docs/进度.md`。**

## 文档规范

| 文件 | 什么时候改 |
|---|---|
| `docs/进度.md` | **每次提交**（必须）|
| `docs/踩坑日志.md` | 踩到新坑时（加在最上面）|
| `docs/测试日志.md` | 跑过测试后（追加）|
| `docs/协议规格.md` | 协议有变化时 |
| `README.md` | 项目定位/用法变化时 |

## 签名

复用密钥（私钥不入库）：
```
keystore: 见 .keystore 路径配置（本机 $HOME/catshare-root/catshare.keystore）
alias:    catshare
storepass/keypass: 从环境变量 HUCHUAN_KS_PASS 读取，默认 catshare123
```

> ⚠️ 私钥**绝不提交**。`build.sh` 优先读 `$HOME/.huchuan-keystore`，缺失时自动生成。

## 安全

- 不提交密钥、token、密码
- 不提交 `build/`、`*.apk`、`*.keystore`
