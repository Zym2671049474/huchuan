## 一句话

类原生 / AOSP / 第三方 ROM 用户的痛点：**身边一堆小米手机开着小兰互传，就你搜不到、也发不出去。**

这个 App 补的就是这块 —— 106 KB，纯 Java，零第三方依赖，装完在通知栏磁贴里，能和小米手机双向互传文件。

## 它解决什么问题

小米手机之间传文件很方便：下拉控制中心，点「小米互传」，附近的小米设备就出现了。

但如果你用的是类原生系统（PixelOS / LineageOS / crDroid / EvolutionX / Pixel Experience……），**这个功能不存在**。

而小米手机开着的「互传」用的是**小米自己的协议**，不是 Google 的 Quick Share，也不是 Nearby Share。所以：

- ❌ 装 Quick Share 搜不到
- ❌ 装 LocalSend 对方也得装 LocalSend
- ❌ 用微信/QQ，得先加好友、还压画质

**互传**做的就是直接实现小米那套协议，让类原生手机伪装成"小米设备"混进去。

## 最重要的一件事：⚠️ 发送需要 root

这个必须提前讲清楚，不然装了发现发不出去会很困惑。

**原因**：小米协议在传输前，发送方要把自己 `p2p0` 网卡的 **MAC 地址**告诉对方，对方靠它连过来。

而这个地址在 Android 10+ **普通 App 读不到**：

```
FileNotFoundException: /sys/class/net/p2p0/address:
    open failed: EACCES (Permission denied)
```

这是 SELinux 层面的拒绝（`p2p0` 属于 `sysfs_net` 域，App 在 `untrusted_app` 域被明确禁止读）。**没有任何公开 API 能绕过**，不是权限没申请，也不是代码写错。

所以能力分两半：

| | 需要 root | 说明 |
|---|---|---|
| **接收**文件 | ❌ 不需要 | 对方连我们，不用读自己的 MAC |
| **发送**文件 | ✅ **需要** | 读不到 MAC 就只能填假地址，对方连不上，卡在协商超时 |

好消息是：**KernelSU / Magisk 授权一次就行**，之后无感。App 会自己检测，没有 root 时直接说明原因，不会让你白等。

## 怎么用

**这个 App 没有桌面图标**（有意去掉，省得占地方），入口只有两个：

### 接收文件

1. 下拉通知栏 → 点「互传」磁贴（变亮 = 正在广播）
2. 让对方在小米互传里搜你 → 发文件过来
3. 点通知完成项，直接打开文件

> 长按磁贴进设置页，可以选「10 分钟」或「永久」。
> ⚠️ 默认 **10 分钟自动关闭** —— 关了对方就搜不到了，这是设计行为，别以为坏了。

### 发送文件

1. 在任意 App 里点「分享」
2. 选「互传」
3. 弹窗里出现附近的设备 → 点它

文件存在 `Download/互传/`

## 为什么做这么小

106 KB，因为**没有用任何第三方库**：

- 纯 Java（无 Kotlin、无 Compose、无 androidx）
- 不用 Gradle 构建，一个 `build.sh` 走完
- 协议层从零重写（参考了 [CatShare](https://github.com/kmod-midori/CatShare)，但没抄代码）

对比：CatShare 5.9 MB。

小不是目的，"能看懂、能改、出问题能查"才是。整个项目连协议细节、每个坑怎么踩的都写在 `docs/` 里。

---

## 已知限制（提前说，免得踩坑）

1. **发送必须 root**（上面详述）
2. **只验证了小米设备**。小米互传协议是小米自己的，理论上小米/红米系列都行，但其他品牌（华为/OPPO/vivo）用的是各自协议，**互通不了**
3. **默认 10 分钟自动关闭**接收，防止一直广播耗电
4. 需要 **Android 10+**（minSdk 29）
5. 无 root 时**只能接收不能发送**

## 适合谁

- 用类原生系统，但身边全是小米手机的人
- 不想为了传个文件去装微信/QQ的人
- 喜欢小体积、无广告、无后台常驻的人

## 不适合谁

- 两台都是小米 → 直接用系统自带互传，比这个好
- 两台都是类原生 → 用 LocalSend，双向都不需要 root
- 没有 root 又想发送 → 这个解决不了
