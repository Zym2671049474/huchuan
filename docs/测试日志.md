## 2026-10-15 — M2 WiFi Direct（真机验证通过）

### T4 — 建组（createGroup）
```
环境：Xiaomi 12 Pro / PixelOS 16.2，Wi-Fi 已开启
方式：am start --ez autotest true（自动测试，无需驱动 UI）

日志：
  权限          ✅ 6/6 已授予
  P2pManager    ✅ 初始化成功
  SSID=DIRECT-rrLvKR1R  PSK=xjihTo3M
  ✅ 建组成功
  会话: GO=true addr=192.168.49.1 ssid=DIRECT-rrLvKR1R iface=p2p0

系统侧证据（独立于 app 日志）：
  ip addr show p2p0
    → state UP
    → inet 192.168.49.1/24        ← 标准组主地址
  dumpsys wifi
    → Connection state: STA=true, P2P=true
结果：✅ 通过
```

### T5 — 广播时序（发现并修复真实竞态）
```
时间线（修复前）：
  16:16:05.134  连接变化 groupFormed=false group=null    ← 中间态
  16:16:05.167  建组成功（ActionListener 回调）
  16:16:05.497  连接变化 groupFormed=true 192.168.49.1   ← 真正的组信息
                ↑ 比回调晚 330ms

问题：原实现用 CountDownLatch 等"第一个" CONNECTION_CHANGED，
      结果被 groupFormed=false 的中间态提前放行 → 会话信息为 null

修复：改为 awaitGroupReady() 轮询 lastSession != null（最多 8s）
验证（修复后）：
  ✅ 建组成功
  会话: GO=true addr=192.168.49.1 ssid=DIRECT-rrLvKR1R iface=p2p0
结果：✅ 通过
```

### T6 — 权限

```
NEARBY_WIFI_DEVICES / POST_NOTIFICATIONS

```
