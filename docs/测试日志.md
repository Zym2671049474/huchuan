```

  16:16:05.497  连接变化 groupFormed=true 192.168.49.1   ← 真正的组信息
```

### 真机观察到的失败模式（17:09 那次）
```
17:09:14.940  已加入: GO=false addr=192.168.49.1        ✅
17:09:15.420  WS 已连接 .../websocket (wss)             ✅ TLS 通了
17:09:15.478  ← versionNegotiation                      ✅
17:09:15.478  → ack                                     ✅
17:09:25.259  连接关闭                                   ❌ 恰好 +10s
17:09:25.408  P2pStateMachine.handleGroupRemoved         ❌ 对方撤组
```
→ 10 秒正是 CatShare 的 `withTimeoutOrNull(10000L)` 用户确认窗口（P026）

### 本轮修复
- `respond(taskId, 99, 1, "ok")` —— id 用 99，对齐 CatShare，且**收到请求立即回**
- 回完 status **马上**发起 /download（对端 transferStartFuture 只等 30s）
- 新增 `HuChuan.Wire` 标签，打印每一帧的 TX/RX，便于下次定位
