## ⬜ M2 — WiFi Direct（下一步）

**目标**：能建组 / 加入组，并拿到 `groupOwnerAddress`

```java
WifiP2pManager manager = (WifiP2pManager) getSystemService(WIFI_P2P_SERVICE);
WifiP2pManager.Channel ch = manager.initialize(this, getMainLooper(), null);

manager.createGroup(ch, actionListener);       // 发送方建组
// 轮询 requestGroupInfo(ch, listener) 拿 SSID/PSK

WifiP2pConfig cfg = new WifiP2pConfig.Builder()
        .setNetworkName(ssid).setPassphrase(psk).build();
manager.connect(ch, cfg, actionListener);      // 接收方加入
```

**参考**：`$HOME/CatShare-src/.../utils/P2pUtils.kt`（70 行，只读）

**注意**：
- 需权限 `NEARBY_WIFI_DEVICES`(API33+) / `ACCESS_FINE_LOCATION`（已在 Manifest 声明）
- `createGroup` 后需轮询 `requestGroupInfo`，不是立即返回
- 需要 `WIFI_P2P_CONNECTION_CHANGED_ACTION` 广播接收器
- **不需要 MAC / root**（见踩坑日志 P001）

**验收标准**：两台设备能建组并互相 ping 通 `groupOwnerAddress`

## 🔑 关键决策

| 决策 | 理由 |
|---|---|
| 纯 Java | 本机无 kotlinc |
| 手写 WebSocket | 无 Gradle，无法引入 Ktor |
| 不用 lambda | 严格 android.jar 缺 LambdaMetafactory（P011）|
| 不实现 MAC/root | 协议死字段（P001）|
| minSdk 29 / targetSdk 35 | 与 CatShare 对齐保证互通 |
