## ⬜ 下一步：双机联调（M6）

**操作步骤见 [`docs/双机测试指南.md`](双机测试指南.md)**

要点：
1. 两台设备都装 `build/huchuan.apk`
2. 开蓝牙 + Wi-Fi + 定位，权限全给
3. B 机点「开始接收」→ A 机点「选择文件发送」

## 🔑 关键决策

| 决策 | 理由 |
|---|---|
| 纯 Java | 本机无 kotlinc |
| 手写 WebSocket | 无 Gradle，无法引入 Ktor |
| 不用 lambda | 严格 android.jar 缺 LambdaMetafactory（P011）|
| 不用 androidx | 无依赖仓库 |
| `java.util.Base64` 而非 `android.util` | 可在 JVM 单测（还是纯 JVM 可测的关键）|
| 不实现 MAC/root | 协议死字段（P001）|
| 发送方 = WS server | 与 CatShare 一致 |
| 等状态就绪而非等广播次数 | P2P 广播有中间态（P016）|

## 给下一个 agent

1. **先读** `docs/双机测试指南.md`，等用户反馈测试结果
2. 根据失败点定位（日志 TAG：`HuChuan.Sender` / `.Receiver` / `.GattClient` / `.Transfer`）
3. 必读踩坑日志 **P001**（死字段）/ **P011**（lambda）/ **P016**（中间态）/ **P018**（分块读写）
4. 改完跑 `./build.sh`（会拒绝错误构建），`./build.sh install`
5. 单测可用纯 JVM（参考 `/tmp/wstest3` 的 JSON shim 方案）——**不需要设备**
6. 完成后更新本文件 + `docs/测试日志.md`
7. 推送：`GH_TOKEN=xxx GH_REPO=Zym2671049474/huchuan node scripts/api-push.mjs`
