# 双机测试指南（互传 ↔ 小米 15）

> 本机（PixelOS / Xiaomi 12 Pro）= **A**；小米 15（HyperOS）= **B**

---

## 准备

### 1. 两边都装好 app

**A 机（本机）**：
```sh
cd ~/huchuan && ./build.sh install
```

**B 机（小米 15）**：把 `build/huchuan.apk` 传过去安装
```sh
# 用任意方式传（QQ/微信/网盘），或
adb install -r huchuan.apk
```
> ⚠️ 小米 15 需允许「安装未知来源应用」

### 2. 打开必要开关（两台都要）

| 开关 | 位置 |
|---|---|
| 蓝牙 | 设置 → 蓝牙 → 开 |
| Wi-Fi | 设置 → WLAN → 开（**不必连热点**）|
| 定位 | 设置 → 位置 → 开（P2P 扫描需要）|

### 3. 授予权限

首次打开 app 会弹权限（蓝牙/位置/附近设备/通知）—— **全部允许**。

## 排查

### A 机日志在哪看
```sh
# 完整日志
logcat -s HuChuan HuChuan.Sender HuChuan.Receiver HuChuan.P2p HuChuan.GattServer HuChuan.GattClient HuChuan.Transfer

# 只看接收
logcat -s HuChuan.Receiver
```

或直接在 app 界面看（日志区）

### 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `未扫描到接收方` | B 机没点「开始接收」/ BLE 权限没给 | 确认 B 机在广播 |
| `建组失败: BUSY` | 上一個 P2P 组没清掉 | 关掉 Wi-Fi 再开，重试 |
| `加入失败` | SSID/PSK 不对 或 距离远 | 两机靠近（<5m）|
| `读取 DeviceInfo 超时` | BLE 连接不稳 | 重试；确认 B 机没杀后台 |
| `对方拒绝` | — | 目前自动接受，不应出现 |
| `下载失败` | P2P 链路断了 | 重试 |
| 卡在「扫描接收方…」 | B 机 app 被系统杀了 | 给两边 app 关掉电池优化 |

### 关掉电池优化（重要）
小米的省电策略会杀掉后台 service：
```
设置 → 应用 → 互传 → 省电策略 → 无限制
```

## ⚠️ 已知风险：与小米原生互通可能不工作

**当前实现是「互传联盟协议的子集」**，已实现：
- ✅ BLE GATT 发现（UUID 与协议一致）
- ✅ WiFi Direct 连接（SSID/PSK）
- ✅ WebSocket 传输（帧格式一致）
- ✅ ECDH + AES 加密（一致）

**可能缺失的**：
- ❓ 小米原生「互传」可能有**额外的握手步骤**或**版本协商字段**
- ❓ 小米可能要求 **MAC 字段有效**（我们填的是 `02:00:00:00:00:00`）
- ❓ 可能依赖 **mDNS/Bonjour** 或**小米私有服务发现**

**结论**：**互传 ↔ 互传 应该能通**（自身协议闭环）；
**互传 ↔ 小米原生 不一定通**，需要真机抓包后再补（这就是 M6）。

如果只求「两台设备互传文件」，测试一/二 就够了。
